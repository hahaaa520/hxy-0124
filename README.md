## 网站内容

- **关于我**：个人介绍、学习经历与关注方向。
- **项目探索**：RFID 盲道导航、闻舟、灵境与 K-Means。
- **比赛成果**：创新创业、程序设计与专业竞赛的成长记录。
- **校园与志愿**：学生工作、团队协作与公益服务。
- **舞台与照片**：音乐剧、宣讲和照片背后的故事。
- **未来方向**：计算机、物理与科研愿望。

## 互动设计

- 宇宙主题开场与原创声音频道。
- 五束人格信号收集与最终星座。
- 项目时间线切换与请求路由实验台。
- 高中、大学双时空成长档案。
- 照片故事与奖项详情弹窗。
- 深色模式和响应式布局。

## 本地预览

这是一个无构建步骤、无 npm 依赖的静态网站。直接打开 `index.html`，或在仓库根目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 技术组成

```text
index.html   页面结构与内容
styles.css   主题、布局、响应式样式与动画
script.js    项目切换、信号收集、弹窗、音频等交互
assets/      照片、项目图片与音频
docs/        README 网站预览图
```

使用原生 HTML、CSS 和 JavaScript，通过 GitHub Pages 发布。
